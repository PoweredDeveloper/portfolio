# Web Development Test Guide

A quick reference with code snippets across different languages.

## JavaScript Examples

```javascript
// Async/await with fetch
async function fetchUser(id) {
  const res = await fetch(`/api/users/${id}`)
  if (!res.ok) throw new Error('Failed to fetch')
  return res.json()
}

// Array methods
const items = [1, 2, 3].map((n) => n * 2)
const sum = items.reduce((a, b) => a + b, 0)
```

Inline code: `console.log('hello')` and `Array.from()`.

## C++ Snippets

```cpp
#include <iostream>
#include <vector>

int main() {
  std::vector<int> nums = {1, 2, 3, 4, 5};
  for (const auto& n : nums) {
    std::cout << n * 2 << " ";
  }
  return 0;
}
```

```cpp
// Smart pointers
auto ptr = std::make_unique<std::string>("hello");
std::shared_ptr<int> shared = std::make_shared<int>(42);
```
