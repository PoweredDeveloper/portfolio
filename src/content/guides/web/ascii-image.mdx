# AsciiImage Component

Renders images or text as ASCII art. Provide exactly one of `imageUrl` or `text`.

## Two Modes

### Image Mode (`imageUrl`)

Converts a photo to ASCII characters by mapping pixel brightness to a charset. Supports reveal animation and idle: subtle pixel mutation to similar characters (same brightness) so the image stays recognizable but alive.

### Text Mode (`text`)

Displays text with reveal effects. Two reveal modes:

- **`messy`**: Fills the container with random chars, centers your text, then reveals it one character at a time. Best when the container is larger than the text.
- **`empty`**: Shuffling chars settle into the final text.

Idle spawns random chars in space positions (main text is never touched). With `fade: true`, chars fade in and out instead of popping.

---

## Options Structure

All settings live under the `options` prop:

```tsx
options={{
  display: { fontSize, scale, cols, rows, textClassName, messyClassName, charset },
  imageProcessing: { contrast, sharpness },  // image mode only
  animation: { animated, duration, revealMode, messinessThreshold, speedFunction },
  idle: { enabled, interval, imageChangeFraction, fade },
}}
```

**display**: `fontSize` (12), `scale` (1), `cols`/`rows` (image mode), `textClassName` ("text-foreground"), `messyClassName` ("text-pale font-light"), `charset`

**imageProcessing** (image mode): `contrast` (1), `sharpness` (1)

**animation**: `animated` (false), `duration` (3000), `revealMode` ("messy" | "empty"), `messinessThreshold` (0.3), `speedFunction`

**idle**: `enabled` (false), `interval` (2000), `imageChangeFraction` (0.01, image mode), `fade` (false, text mode)

## Image Mode Examples

### Basic image

```tsx
<AsciiImage
  imageUrl="/photo.jpg"
  className="max-w-md"
/>
```

### Image with animation and idle

```tsx
<AsciiImage
  imageUrl="/photo.jpg"
  options={{
    display: { cols: 80, rows: 40, fontSize: 8 },
    animation: { animated: true, duration: 2000 },
    idle: {
      enabled: true,
      interval: 1500,
      imageChangeFraction: 0.02,
    },
  }}
/>
```
