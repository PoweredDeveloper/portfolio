## Multi-stage Builds

Reduce final image size by using multi-stage builds:

```dockerfile
# Build stage
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# Production stage
FROM node:20-alpine
WORKDIR /app
COPY --from=builder /app/dist ./dist
COPY --from=builder /app/node_modules ./node_modules
CMD ["node", "dist/index.js"]
```

## Layer Ordering

Put frequently changing layers last to leverage cache:

```dockerfile
COPY package.json package-lock.json ./
RUN npm ci
COPY . .
```
